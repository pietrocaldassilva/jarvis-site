Guia de instalação

O Jarvis não se instala baixando um .zip neste site. Este site é só o guia (+ assistente). O código fica no repositório privado: você recebe a pasta do projeto (clone ou cópia autorizada) e roda os scripts de instalação dentro dela.

Como funciona
  1. Dono libera o projeto (pasta Jarvis completa).
  2. Você instala Python, Node e Ollama no seu PC/Mac.
  3. Na pasta: Windows instalar.bat → iniciar.bat · Mac ./iniciar.sh.
  4. Atualizações depois: chave no app (não precisa do PC do dono ligado).

A chave do site não baixa o código. Sem ela, só a descrição pública aparece.

Guia liberado neste navegador.

Descrição

O Jarvis é um assistente pessoal 100% local: HUD, voz em português, IA via Ollama e análise de sites.

  • Roda só naquele PC/Mac — não usa o computador de outra pessoa como servidor.
  • Instalação = pasta do projeto + scripts (instalar.bat / iniciar.sh), não um instalador .zip público.
  • Área Sites: adicionar URL → analisar com IA (tudo local).

Passo a passo

Antes de tudo: peça ao dono a pasta do projeto Jarvis (acesso ao repositório privado ou cópia da pasta). Não procure um .zip de instalação neste site — ele não existe aqui.

Windows Mac

Windows

1

Programas base

  • Python 3.11+ — marque Add python.exe to PATH.
  • Node.js LTS
  • Ollama — abra uma vez após instalar.
2

Modelo de IA

No Prompt de Comando ou PowerShell:

ollama pull qwen3:4b

PC mais fraco: ollama pull qwen2.5:3b.

3

Receba o projeto

Coloque a pasta do Jarvis num caminho simples, por exemplo C:\Jarvis. Tem que existir iniciar.bat e instalar.bat dentro dela.

4

Preparar o ambiente

Dois cliques em:

instalar.bat

Cria o ambiente Python e instala as dependências. Espere terminar.

5

Abrir o Jarvis

iniciar.bat

Permita o microfone se pedir. A HUD roda local neste PC.

6

Sites (opcional)

Configurações → Sites → nome + URL → Adicionar → Analisar com IA.

Mac

1

Programas base

  • Python 3.11+ (python.org ou brew install python)
  • Node.js LTS
  • Ollama
2

Modelo de IA

No Terminal:

ollama pull qwen3:4b
3

Receba o projeto

A pasta do Jarvis (com iniciar.sh) deve estar no Mac, por exemplo em ~/Desktop/Jarvis. Não use um “instalador zip” deste site.

4

Abrir o Terminal na pasta

  1. Spotlight (Cmd+Espaço) → Terminal
  2. Ou no Finder: arraste a pasta do Jarvis para o ícone do Terminal
  3. Confirme com pwd e ls que vê iniciar.sh
5

Instalar e abrir

chmod +x iniciar.sh iniciar.command
./iniciar.sh

Na primeira vez cria o ambiente e instala os pacotes. Depois sobe a HUD.

Ou dois cliques em iniciar.command.

6

Sites (opcional)

HUD → Sites → Adicionar → Analisar com IA. Tudo local neste Mac.

Atualizar depois

Com o projeto já na máquina: use a chave de atualização no app (é outra chave, não a do site). O dono não precisa estar online.

1

Chave de atualização

Token GitHub (leitura) que o dono te envia.

2

Colar no Jarvis

Configurações → Sistema → salvar chave.

3

Atualizar Jarvis

Botão Atualizar Jarvis. Preserva dados e sites. Reinicie com iniciar.bat ou ./iniciar.sh.
