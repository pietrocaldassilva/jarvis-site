Descrição

O Jarvis é um assistente pessoal 100% local: HUD, voz em português, IA via Ollama e análise de sites (cadastra a URL e a IA resume o negócio).

  • Roda só naquele PC/Mac — não usa o computador de outra pessoa como servidor.
  • Área Sites: adicionar → analisar com IA → ver resumo.
  • Atualização pelo próprio app (com chave), sem precisar do PC do autor ligado.

Passo a passo

Você precisa de duas coisas do dono: a pasta/ZIP do Jarvis e a chave de atualização (depois). Este site não baixa o código.

Windows Mac

Windows — instalação

1

Instale os programas base

  • Python 3.11+ — na instalação, marque Add python.exe to PATH.
  • Node.js LTS — Next até o fim.
  • Ollama — instale e abra uma vez.
2

Baixe o modelo de IA

Abra o Prompt de Comando ou PowerShell e rode:

ollama pull qwen3:4b

Em PC fraco, use ollama pull qwen2.5:3b.

3

Receba a pasta do Jarvis

Pendrive, e-mail ou release privada do dono. Extraia o ZIP numa pasta simples, por exemplo:

C:\Jarvis
4

Instale as dependências

Abra a pasta do Jarvis e dê dois cliques em:

instalar.bat

Espere terminar sem fechar a janela preta.

5

Abra o Jarvis

Dois cliques em:

iniciar.bat

Na HUD: permita o microfone se o navegador pedir. Pronto.

6

Sites (opcional)

Na HUD → Configurações → Sites → nome + URL → Adicionar → Analisar com IA.

Mac — instalação

1

Instale os programas base

  • Python 3.11+ (pelo site python.org ou brew install python)
  • Node.js LTS
  • Ollama — abra o app uma vez
2

Baixe o modelo de IA

Abra o Terminal (Spotlight → digite Terminal) e rode:

ollama pull qwen3:4b

Mac Intel mais fraco: ollama pull qwen2.5:3b.

3

Receba a pasta do Jarvis

Extraia o ZIP, por exemplo em:

~/Desktop/Jarvis
4

Como abrir o Terminal na pasta

  1. Abra o Finder na pasta do Jarvis.
  2. Menu Finder → Serviços → Nova janela do Terminal na pasta (ou arraste a pasta para o ícone do Terminal no Dock).
  3. Ou no Terminal: cd, espaço, arraste a pasta e Enter.
5

Instale e abra

No Terminal, na pasta do Jarvis:

chmod +x iniciar.sh iniciar.command
./iniciar.sh

Na primeira vez ele cria o ambiente e instala os pacotes sozinho. Depois abre a HUD.

Alternativa: dois cliques em iniciar.command no Finder.

6

Sites (opcional)

Na HUD → Sites → nome + URL → Adicionar → Analisar com IA. Tudo fica no Mac dele — o PC do dono não precisa estar ligado.

Atualizar depois

Serve para Windows e Mac. Não precisa do PC do dono ligado.

1

Pegue a chave de atualização

É um token GitHub (só leitura) que o dono te passa. É outra chave, diferente da chave deste site.

2

Cole no Jarvis

Abra o Jarvis → Configurações → Sistema → campo da chave → Salvar chave.

3

Atualizar

Clique em Atualizar Jarvis. O app baixa a release, troca os arquivos e preserva seus dados e sites.

4

Reinicie

Windows: iniciar.bat · Mac: ./iniciar.sh

URL deste guia: pietrocaldassilva.github.io/jarvis-site — não use …/jarvis/ (dá 404; o código é privado).
