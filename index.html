Descrição

O Jarvis é um assistente pessoal 100% local: HUD cinematográfica, voz em português, IA via Ollama e análise de sites (cadastra a URL e a IA resume o negócio).

  • Roda só naquele PC/Mac — não usa o computador de outra pessoa como servidor.
  • Área Sites: adicionar → analisar com IA → ver resumo (público, contato, destaques).
  • Atualização pelo próprio app (com chave), sem precisar do PC do autor ligado.

Passo a passo (Mac)

  1. Instale Python 3.11+, Node.js LTS e Ollama; rode ollama pull qwen3:4b.
  2. Receba a pasta/ZIP do Jarvis direto do dono (pendrive ou release privada) — não há download anônimo do código.
  3. No Terminal, na pasta: chmod +x iniciar.sh && ./iniciar.sh
  4. HUD → Sites: nome + URL → Adicionar → Analisar com IA.
  5. Sistema → cole a chave de atualização → Salvar → Atualizar Jarvis quando houver versão nova.

Windows

  1. Python (PATH) + Node LTS + Ollama (ollama pull qwen3:4b).
  2. Receba o pacote do dono → instalar.bat → iniciar.bat.
  3. Mesma aba Sites / Análise e Sistema → chave → Atualizar.

Atualizar sem o outro PC

  1. O dono publica uma release no GitHub (privado) e te passa a chave de atualização (token só de leitura).
  2. No Jarvis: Configurações → Sistema → colar chave → Salvar.
  3. Clique em Atualizar Jarvis. O app baixa o ZIP da release, atualiza os arquivos e preserva seus dados/sites.
  4. Reinicie com ./iniciar.sh ou iniciar.bat.

Sem a chave, ninguém baixa o pacote. O site público não hospeda o código-fonte.
