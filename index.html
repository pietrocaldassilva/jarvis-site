Instalar o Jarvis

Este site é o instalador: com a chave de instalação (token GitHub) você baixa o pacote e coloca o projeto no PC. O código-fonte continua privado.

Ir para download

Download

Detectando sistema…

Cole a chave de instalação (token GitHub). Sem acesso ao repo privado o GitHub responde «não encontrado».

Se der «não encontrado»
  • Token fine-grained: repo pietrocaldassilva/jarvis + Contents: Read.
  • Ou token classic com escopo repo (privado).
  • Use Instalador automático (recomendado) — o ZIP direto no navegador costuma falhar por bloqueio do GitHub.

Requisitos (uma vez no PC)

Antes ou depois do download, instale estes programas no computador onde o Jarvis vai rodar:

  • Python 3.11+ — no Windows marque Add to PATH
  • Node.js LTS
  • Ollama + no terminal: ollama pull qwen3:4b

Depois do download

Windows

1

Pacote ou script

Se baixou o pacote: extraia a pasta. Se usou o instalador automático: a pasta fica em %USERPROFILE%\Jarvis.

2

Preparar

instalar.bat
3

Abrir

iniciar.bat

Mac

1

Pacote ou script

Extraia o pacote ou use o instalar-jarvis.command (pasta em ~/Jarvis).

2

Abrir

cd ~/Jarvis
chmod +x iniciar.sh
./iniciar.sh

Na primeira vez o script já instala as dependências.

Atualizar depois

Com o Jarvis já instalado, use a mesma chave em Configurações → Sistema → Atualizar Jarvis.

  1. Abra o Jarvis.
  2. Configurações → Sistema → colar chave → Salvar.
  3. Atualizar Jarvis → reinicie com iniciar.bat ou ./iniciar.sh.
